1단계. 제목 해석

* 제목에 나타난 행사명, 기관명, 정책대상, 업무행위, 지원행위를 분리하세요.

2단계. 행사 관련성 판단

* 기록물 제목이 특정 국가 행사와 직접 또는 간접적으로 관련되는지 판단하세요.

3단계. 정부 활동 단계 판단

다음 중 하나를 선택하세요.

* 기획 : 행사계획, 기본계획, 종합계획, 추진계획, 시행계획, 준비계획, 운영계획, 개최계획, 전략수립
* 집행 : 행사추진, 행사운영, 지원, 홍보, 점검, 협의, 교육, 회의운영, 예산집행, 현장관리
* 대응 : 행사 관련 안전관리, 비상대응, 상황관리, 민원대응, 긴급조치
* 해결·결과 : 결과보고, 평가, 성과분석, 정산, 후속조치, 백서, 종합보고
* 검토 필요 : 제목만으로 단계를 판단하기 어려움

4단계. 후보 행사 선정

* 제공된 행사 후보 목록에서 관련 가능성이 높은 후보를 1가지만 선정하세요.
* 후보 선정 시 다음을 함께 고려하세요.

  * 제목의 핵심 키워드
  * 제목이 의미하는 업무영역
  * 생산기관의 소관업무
  * 행사 후보의 판단 기준

5단계. 오분류 검증

최종 매핑 전에 반드시 아래 오분류 검사를 수행하세요.

다음에 해당하면 “매핑”하지 말고 “제외”로 판단하세요.

* 제목이 너무 일반적이어서 특정 행사를 식별할 수 없는 경우
* 단순 회의 개최, 회의 참석, 출장, 의전, 자료 송부, 문서 접수에 불과한 경우
* 일반 예산, 인사, 서무, 계약, 물품관리, 내부행정에 해당하는 경우
* 행사명과 무관한 일반 정책업무인 경우
* 생산기관의 소관업무와 행사 성격이 명확히 맞지 않는 경우
* 단순 국제교류 또는 기관방문으로 국가행사와 연결되지 않는 경우
* 제목만으로 특정 행사와의 직접 연결 근거가 부족한 경우
