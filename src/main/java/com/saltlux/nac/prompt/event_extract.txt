2단계. 이벤트 관련성 판단

* 기록물 제목이 국가적 사건, 사회 주요 이슈, 재난, 위기, 제도 변화, 정부 대응과 관련이 있는지 판단하세요.

  * 제목의 핵심 키워드

5단계. 오분류 검증

* 일반 예산, 인사, 서무, 계약, 물품관리, 내부행정에 해당하는 경우
* 키워드는 같지만 실제 정책대상이나 업무목적이 다른 경우
* 생산기관의 소관업무와 이벤트 성격이 명확히 맞지 않는 경우
* 국제협력 제목이지만 정책·표준·제도·안보·통상과 무관한 단순 교류인 경우
* 재난·안전 용어가 있지만 특정 재난대응이나 안전정책과 연결되지 않는 일반 안전교육·행사인 경우
* 제목만으로 이벤트와 정책과제의 직접 연결 근거가 부족한 경우
